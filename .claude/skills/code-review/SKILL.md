# Code Review

## Шаги

1. **Определи изменения**
   - `git diff main...HEAD --stat` (или `git diff` если нет main)
   - Прочитай полный дифф

2. **Проверь каждый файл по чек-листу**
   - **Корректность**: логика, граничные случаи, обработка ошибок
   - **Безопасность**: секреты, валидация данных из сети и с диска
   - **Производительность**: лишняя работа на каждом кадре, утечки подписок/таймеров, большие синхронные чтения файлов
   - **Стиль**: соответствие CLAUDE.md

3. **Специфично для Overdrive**
   - Стиль реконструированного кода сохранён (`var`, `(0, jsx)(...)`), файл не переформатирован целиком
   - В шапке изменённого файла есть строка `// MODIFIED: ...`
   - Новые строки UI есть во всех 14 `app/i18n/locales/*.json`, плейсхолдеры совпадают
   - RTL (ar, ur) учтён в отступах
   - Работа с геймпадом: фокус (`focusKey`), ✕ / ○, L1/R1
   - `ps5-react/` не тронут
   - Если меняется версия — `app/version.js` и `app/app.json` подняты вместе

## Формат отчёта

```markdown
## Итог: <одно предложение>

### 🔴 Критично
- `файл:строка` — проблема → предложение

### 🟡 Стоит исправить
- ...

### 🟢 Мелочи
- ...
```
